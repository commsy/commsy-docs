# Mail text placeholders

## Deprovisioning

- Lock room after X days:
  - %1: Room title
  - %2: Number of inactive days
  - %3: Number of days until lock

- Room will be automatically deleted after X days:
  - %1: Room title
  - %2: Number of inactive days
  - %3: Number of days until deletion

- Lock user ID in X days:
  - %1: Account name
  - %2: Name of authentication source
  - %3: Number of days until lock
  - %4: Link to portal
  - %5: Portal title

- User ID was locked:
  - %1: Account name
  - %2: Name of authentication source
  - %3: Link to portal
  - %4: Portal title

- Delete user ID in X days:
  - %1: Account name
  - %2: Name of authentication source
  - %3: Number of days until deletion
  - %4: Link to portal
  - %5: Portal title

- User ID was deleted:
  - %1: Account name
  - %2: Name of authentication source
  - %3: Link to portal
  - %4: Portal title
